# Toby Studio

Portfolio of Tobiloba Julius — UI/UX, landing pages, mobile apps and AI-built websites.

A single static page (`index.html`), no build step. Deploy by importing this repository into Vercel (framework preset: **Other**).

## Updating content

Everything editable lives in the arrays at the bottom of `index.html`:

- `projectData` — case studies (images in `assets/img/<folder>/`, with `-t.webp` thumbnails)
- `aiProjects` — AI-built websites (videos in `assets/video/`, posters in `assets/img/ai/`)
- `playground`, `steps`, `testimonials`

Images are WebP (max 1600px wide); videos are 720p H.264 without audio.
